## Zavly (2026) · private repositories

AI-native prospecting service for B2B sales teams, which I founded and built alone with Claude Code. It reached 5 paying clients in 8 months.

- **Stack:** Node, React/TypeScript, PostgreSQL and the Claude API, integrated with HubSpot, Pipedrive, WhatsApp and third-party data APIs.
- **Quality:** evals to measure the agents' output.
- **How I worked:** Claude Code with Git/GitHub, bringing in a freelance developer when needed.
